## Authorship & Attribution

This application was built by **Claude**, an AI model created by
**Anthropic**, under the guidance of **Keith Francis, GitHub username
keithintrinidad**.

The app's concept, a pocket companion for Mass and Eucharistic Adoration,
was inspired by the *Mass and Adoration Companion* of Vinny Flynn and
Erin Flynn. No text from that book is used. The original prayers, the
notes on each part of the Mass, and the Holy Hour guide were written by
Claude, drawing on Keith Francis's conversations with it about Scripture,
its Hebrew and Greek background, and worship. Keith Francis directed the
app's design, content, and features through conversation with Claude,
but did not write the code directly.

Any copy, fork, or derivative of this project must retain this notice,
crediting both Claude/Anthropic as the builder and Keith Francis
(keithintrinidad) as the person who directed its creation.

A short version of this notice, and a summary of these terms, is also
shown inside the app itself via the (i) information button.
